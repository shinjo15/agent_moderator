1. 本拡張について

Agent Moderatorは、開発者が私的時間に個人で開発するChrome拡張機能です。Google・YouTube・TypeSafeの公式拡張ではありません。

利用者が選んだYouTubeライブ配信のチャットを公式APIで取得・表示し、任意のJev判定と端末内の連投判定により、対象投稿者を配信者のチャンネル別の端末内リストへ保存します。同じ配信者の別ライブに引き継ぎ、他の配信者には適用しません。非表示は拡張の独立ビューアーだけに適用します。利用者本人の画面を含め、YouTubeのページ・プレイヤー・標準チャット・リプレイの表示や操作は変更しません。BANや投稿削除は行いません。判定項目・基準や操作の詳細は導入・操作手順をご確認ください。

2. 確認と同意

利用規約案・プライバシーポリシー案と、設定画面の送信・費用説明を読み、同意する場合にチェックして「同意を保存」を押してください。同意は開発版の案に対するもので、正式施行や公開承認とは別です。インストール・文書の閲覧・キー保存だけで同意したとは扱いません。

未同意の間はYouTube APIによる取得とJev送信を開始できません。同意の保存だけでは取得・判定を自動開始せず、Jevは別途明示的な有効化が必要です。通常のYouTubeページ閲覧はこの同意の対象外です。

3. 外部サービスと費用

本拡張はYouTube API Servicesを使用します。本拡張の利用に際して、利用者はYouTube利用規約に拘束されます。Googleによる情報の取り扱いはGoogleプライバシーポリシーをご確認ください。

現在は利用者本人が用意したYouTube・Jev APIキーを設定する方式です。YouTube APIの利用枠（クォータ）とJevの利用料金は利用者負担です。提供元の契約、料金、利用枠を確認してください。キーの保存は接続・認証成功や利用可能枠の確認ではありません。

JevにはTypeSafeのAPIサービスの契約とプライバシーポリシー、利用者の個別契約・設定が関係します。本拡張への同意だけで、外部サービスの利用条件を満たしたことにはなりません。

4. 外部送信と情報の取り扱い

取得開始後はGoogleへAPIキーや対象配信の情報を送り、チャットを取得します。Jevを明示的に有効にした場合は、悪質性の判定のためTypeSafe AIへ対象コメントの本文・投稿時刻と、同じ投稿者の直近の取得済みコメントを送ります。AI・連投で最初に非表示登録した対象の本文を「登録時のコメント」として、配信者チャンネル・投稿者ごとに1件だけ元の動画IDと端末内保存します。後続投稿で上書きせず、同じ配信者の別ライブでも元の本文を表示します。全コメント履歴の保存や、この表示のための追加外部送信は行いません。個別解除・全削除では保存本文と元の動画IDも削除します。説明の版4への再同意が必要ですが、既存一覧の確認・解除・全削除は未同意でも可能です。具体的な送信範囲、認証、保存、外部サービス側の処理はプライバシーポリシーをご確認ください。

本文には個人情報が含まれ得ます。本文の自動匿名化はありません。利用者の同意は投稿者本人の同意ではなく、第三者の権利・必要な通知や同意を代替しません。第三者の投稿の送信条件や提供元の用途適合性は確認中です。

5. 判定・表示の限界

誤判定や見逃し、取得・通信の失敗、画面反映の遅延があり得ます。判定は投稿者の人格や法的な違法性を確定するものではありません。非表示の対象は一覧から確認・解除できます。実APIでの判定精度・速度等は未検証です。

6. 停止・解除・削除

「Jev判定を停止」はJev送信を、「取得を停止」は取得と判定を止めます。停止だけでは保存済みの非表示リストを削除しません。解除・全削除では独立画面の保持中の対象行だけ再表示し、失った過去コメントは復元しません。YouTubeの表示は変更しません。

対象配信者の一覧から個別に「非表示を解除」でき、同じ配信者の別ライブにも反映します。「全配信の非表示データを削除」は新旧の非表示ID・名前・解除の世代情報・移行済み動画の記録を削除しますが、APIキーなどの設定は残します。設定でのキー削除と、提供元でのキー失効・解約は別です。

拡張のアンインストールで拡張の端末内保存を削除できます。これらの操作で、YouTube上の投稿や外部サービスへ送信済みの情報は削除できません。保持範囲と削除手順はプライバシーポリシーをご確認ください。
