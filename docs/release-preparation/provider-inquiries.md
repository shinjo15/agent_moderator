### 件名／用途名

Agent Moderator：視聴者向けライブチャットフィルターの公開前適合性確認

### 本文案

YouTube API Servicesご担当者様

開発中のChrome拡張「Agent Moderator」を一般利用者へ配布する前に、以下の用途がYouTube API Servicesの規約・Developer Policiesに適合するか確認したいと考えています。現時点でこの用途の監査・承認は受けていません。

対象利用者はYouTubeライブ配信の視聴者です。配信者・モデレーターによるBANやコメント削除を行うツールではありません。

現在の構成は次のとおりです。

1. 利用者が選んだ配信について、YouTube Data APIのvideos.listとliveChatMessages.listを使用してライブチャットを取得します。APIのページトークンと取得待機時間に従います。終了した配信のチャットリプレイは対象外です。
2. 利用者が明示的にJev判定を有効にした場合、取得したコメントを1件ずつTypeSafe AIのJev APIへ送り、攻撃・差別／憎悪・脅迫／危害扇動・性的嫌がらせ・個人情報の晒し・スパム・無関係な宣伝の7項目のスコアを取得します。補足として同じ投稿者の直近60秒以内の取得済みコメントを、判定対象込みで最大20件添えます。
3. Jevに渡す投稿データは本文と投稿時刻です。投稿者ID・表示名・動画IDは投稿データに含めません。ただし、本文中に個人情報が含まれる可能性があり、自動マスキングは現状実装していません。API認証用の利用者のJevキーはTypeSafeへの認証ヘッダーに使用します。
4. スコアと利用者が保存した判定基準に基づき、対象投稿者を配信別のローカル非表示一覧へ登録します。また、取得済みID・投稿時刻から10秒以内10件の連投を判定します。判定スコアは拡張の画面に表示します。
5. YouTubeのライブチャット画面では安定した投稿者IDを照合し、その視聴者の画面上だけで対象投稿者の既存・新着コメントを非表示にします。YouTubeサーバー上の投稿・BAN状態や、他の視聴者の画面は変更しません。プレイヤーや広告には作用しません。
6. 本文・評価履歴はアーカイブせず、一時保持を期限・件数で制限しています。閲覧用の直近200件は監視画面を閉じるまで表示され得ます。一方、配信IDに紐づく非表示投稿者ID・取得した表示名・解除の世代情報はChromeプロファイル内に保存されます。非表示IDは明示解除まで保持し、自動期限や定期API更新は現状ありません。解除後も再登録防止用の世代情報が残ります。
7. 独自バックエンドはなく、Google／TypeSafeへ利用者の端末から直接通信します。現在は各利用者自身のYouTube・Jev APIキーを入力する方式です。開発者のキーは配布しません。

以下について適合性の判断と、必要な変更・追加資料・承認手続をご教示ください。

- III.E.4.h等の派生データ・指標の制限に対し、上記の外部AIスコア生成と連投判定は認められますか。別途の許可申請が必要ですか。Analytics向けの特例が本用途に適用できるとは想定していません。
- III.Iの表示・機能変更制限に対し、視聴者が明示的に使用する配信別フィルターと、DOM上の投稿者ID照合・チャット行非表示は認められますか。作者名・リンクの表示／非表示について必要な要件はありますか。
- API由来の配信ID・投稿者ID・表示名を含むローカル非表示設定と解除世代情報に対して、保存期間・30日以内の削除／更新・削除要求の要件はどう適用されますか。
- 公開チャット本文を外部推論サービスへ送ることは認められますか。視聴者の同意に加えて必要な権利・通知・同意要件はありますか。
- 各利用者自身のGoogle CloudプロジェクトのAPIキーで同一拡張を利用する配布方式は、複数プロジェクト・クォータ分散に関する制限と整合しますか。開発者側で監査対象とするプロジェクトや運用方法はどうすべきでしょうか。
- 公開前に必要なプライバシーポリシー、同意導線、YouTube／Google規約リンク、帰属表示、削除機能について、この用途に固有の要件はありますか。

一般公開は適合性確認と必要な対応を終えるまで保留する予定です。未対応の保存期間・同意・公開文書等を、現状で対応済みと申告するものではありません。

### 件名

Jevを利用した視聴者向けチャットフィルターの公開前確認（第三者コメント・利用者自身のAPIキー・データ保持）

### 本文案

TypeSafeご担当者様

Chrome拡張「Agent Moderator」を開発しています。一般利用者への配布前に、Jev APIの利用条件と入力データの取り扱いを確認したくご連絡します。

本拡張はYouTubeライブチャットの視聴者向けフィルターです。YouTube公式APIで取得したコメントを、利用者が明示的に判定を有効にした後、1件ずつJevへ送ります。同じ投稿者の取得済みコメントを直近60秒・対象込み最大20件まで補足として添えます。7項目のスコアを取得し、対象投稿者のコメントをその視聴者の画面だけで非表示にします。BAN・投稿削除・モデル学習は本拡張では行いません。

Jevの投稿データは本文と投稿時刻だけで、投稿者ID・名前・動画IDは含めません。ただし、第三者の公開コメントには個人情報、差別・脅迫等の内容、未成年者の情報が含まれる可能性があり、自動匿名化は未実装です。送信者は必ずしも投稿者本人ではなく、視聴者の同意だけを投稿者の同意とは扱っていません。

独自バックエンドはなく、各利用者が自分のTypeSafeアカウントで発行したJev APIキーを拡張に保存し、端末から直接APIへ通信します。開発者キーの共有やTypeSafe API自体の再販売を目的としていません。YouTube側の適合性は別途確認予定であり、御社の回答だけで第三者の権利やYouTube規約への適合が確定するとは考えていません。

以下をご確認いただけますでしょうか。

1. このモデレーション用途と、各利用者自身のAPIキーを使う公開拡張への組み込みは、MCA・AUP・Documentation上認められますか。開発者と各利用者の契約上の役割、必要な手続をご教示ください。
2. 公開チャットの第三者投稿を推論へ送る場合、必要な権利・通知・同意にはどのような要件がありますか。個人情報、未成年者の情報、悪質・違法な内容を検知目的で処理する際の禁止事項や必要措置も確認したいです。
3. API入力・出力、ログ、Telemetry、バックアップの保持期間と用途をそれぞれ教えてください。担当者・委託先による閲覧の条件も確認したいです。
4. 公開Privacy Policyの入力を学習しない記載と、MCAの事前同意に関する条件、個別Orderとの関係を教えてください。各利用者が確認すべき設定や例外はありますか。
5. ゼロ保持や保持期間の短縮を利用できますか。利用可能なプラン・手続・対象データを教えてください。送信済みの第三者投稿に削除要求があった場合の手続、削除期限、バックアップの扱いも確認したいです。
