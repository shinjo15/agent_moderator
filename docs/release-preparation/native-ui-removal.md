# Issue #40：YouTube本体UI変更撤去・公開差替えチェック

本書は実装と公開作業を区別するためのチェックリスト。ストア更新・画像作成・デモ録画・メール送信・再審査依頼は本作業では未実施。

## 対応範囲

親から共有されたYouTubeレビューのIII.F.1に基づき、YouTubeのページ・プレイヤー・ライブチャット・リプレイのUI変更を撤去する。初期OFFや条件ガードで旧処理を温存しない。content/MAIN script、DOM識別・監視・定期反映・表示変更、旧contentのID一覧応答・referrer照合、注入build/ZIP entry、YouTube originのhost権限を削除する。動的注入、オーバーレイ、自動チャット閉鎖・ブロッククリック、非公開API、本文スクレイピングで代替しない。

公式API取得、Jev・連投判定、保存・一覧・解除・全削除、同意・キー保護・停止境界は維持する。保存key/型や既存データを破棄しない。拡張内コメントの実際の非表示と閲覧UI・フィルタリングはIssue #41で未実装。#37・#38・#39の機能追加も含めない。

## 残した権限・通知

- storage：キー・設定・同意・配信別保存リストとsession制御。
- activeTab：アイコン操作による視聴タブURLの参照と公式API対象の選択・現在動画照合。ページDOMへの介入には使わない。
- https://www.googleapis.com/*：YouTube公式API。
- https://api.typesafe.ai/*：明示有効化したJev判定。
- hidden.clearing/hidden.refresh：拡張monitorの停止と一覧更新。YouTubeへは配信・適用しない。

## 更新案内

拡張の更新・再読み込みだけで、既に開いたYouTubeタブの旧スクリプトや非表示スタイルが消えるとは限らない。視聴タブ（チャットiframeの親）、popout、リプレイを含む全タブを再読み込みするか閉じて開き直すよう案内する。保存リストの全削除やアンインストールを更新の必須手順にしない。
