# プライバシーポリシー（案）

- 最終更新日：2026-10-08（日本時間）
- 施行日：未定（公開時に確定）

本書は、Chrome拡張機能「Agent Moderator」の実装に基づく、GitHub mainに掲載中のプライバシーポリシー案です。正式施行前の案であり、掲載は正式な施行、一般配布の開始、提供元による承認・規約適合の確認が済んだことを意味しません。

## 1. 対象と利用目的

本拡張は、利用者が選んだYouTubeライブ配信のチャットを取得・表示し、任意に有効化するJev判定と端末内の連投判定に基づき、配信ごとに投稿者のコメントを利用者自身の画面で非表示にするものです。取得・判定、表示、配信別の非表示・解除、設定の保存のために、以下の情報を扱います。YouTube上のBANや投稿削除、他の視聴者の画面の変更は行いません。

本拡張は **YouTube API Services** を使用します。本拡張の利用に際して、利用者は[YouTubeの利用規約](https://www.youtube.com/t/terms)に拘束されます。Googleによる情報の取り扱いは、[Googleのプライバシーポリシー](https://policies.google.com/privacy)もご確認ください。[1][2][7]

開発者の収集用サーバーへチャットやAPIキーを送信する機能、広告・アクセス解析機能、開発者のモデル学習を目的とする送信機能は実装していません。ただし、端末内だけで完結するオフラインの拡張ではありません。以下のGoogle／TypeSafeへの通信があります。

## 2. 取得する情報と外部への送信

初回の機能利用前に、同じpopup内の設定画面で本案・YouTube利用規約・Googleプライバシーポリシーと送信説明を確認し、「利用条件・データの扱いを確認しました」にチェックして「利用条件の確認を保存」を押します。未確認、旧版、保存情報の欠落・不正、読取失敗時は、バックグラウンドでYouTube取得・Jev送信を開始しません。説明の版が変わった場合は再確認が必要です。キーの保存や通常のYouTubeページ閲覧はこの確認の対象外です。確認だけで取得・判定を自動開始せず、Jevは別途明示有効化が必要です。この利用者の確認は投稿者本人の同意ではありません。

1. 拡張アイコンの画面で配信を選択すると、対象の動画IDとタブの情報を扱い、その配信の監視画面を開きます。
2. 監視画面で「取得を開始」を押すと、GoogleのYouTube Data APIに通信し、ライブチャットの本文、投稿時刻、コメントID、投稿者ID、取得できる投稿者名、投稿の種類、次の取得に必要な情報を受け取ります。DOMから本文を収集してAPIの代わりにすることはありません。YouTubeチャットのDOMは投稿者IDの照合と画面内の表示制御に使用します。
3. 「Jev判定を有効化・再開」を押した場合、有効化後に取得するコメントを対象に、TypeSafe AIのJev APIへ悪質性の判定を依頼します。7項目を1回の要求にまとめ、対象を1件ずつ順に処理します。ローカルの連投判定だけではJevへの通信を必要としません。

| 送信先 | 送る情報 | 目的・時点 |
| --- | --- | --- |
| Google：`https://www.googleapis.com/youtube/v3/videos` | 利用者のYouTube APIキー、動画ID、取得項目 | 取得開始後、その配信のライブチャットIDを解決するため |
| Google：`https://www.googleapis.com/youtube/v3/liveChat/messages` | 利用者のYouTube APIキー、ライブチャットID、ページトークン、取得項目 | 取得中にチャットを継続して受け取るため |
| TypeSafe AI：`https://api.typesafe.ai/v1/systemone` | 認証用のJev APIキー、モデル指定、固定7項目の質問、下記の投稿データ | Jev判定を有効にした後、悪質性を推論するため |

Jevに渡す投稿データ（`state`）は、対象コメントの本文と投稿時刻（取得・確認できた場合）、および**同じ投稿者**の対象以前・**60秒以内**の取得済みコメントの本文と投稿時刻です。**対象を含め最大20件**で、別の投稿者の履歴、投稿者ID・投稿者名・動画ID・コメントIDは投稿データに含めません。文脈のための追加履歴APIや、失われた本文の再取得は行いません。

「投稿データにAPIキーを含めない」ことと、「認証のためにキーを送る」ことは別です。YouTube APIキーはGoogleへの要求に、Jev APIキーはTypeSafeへの `Authorization` ヘッダーに使用します。API通信はHTTPSで行い、拡張の要求ではブラウザのCookieを送信しません。通信先はIPアドレスなどの接続情報を受け取り得ます。通常のYouTubeサイトの閲覧や問い合わせメールの処理は、このAPI通信とは別です。[2][3]

本文には氏名、住所、連絡先などの個人情報や、センシティブな内容が含まれる可能性があります。**本文の匿名化・個人情報の自動マスキングは実装していません。** IDを投稿データから除いても、完全に匿名になるわけではありません。利用者がJevを有効にしたことは、投稿者本人の同意を取得したことを意味しません。第三者の投稿を送信するために必要な権利・通知・同意は別途確認が必要です。[4]

YouTube APIの利用枠（クォータ）とJevの利用料金は利用者負担です。キーの保存だけではAPI接続・認証の確認をしません。

## 3. 端末内に保存する情報と保持期間

### 継続して保存する情報

次の情報は、利用中のChromeプロファイルにある拡張専用の `chrome.storage.local` に保存します。画面の再読み込み、拡張のバックグラウンド処理やブラウザの再起動後も残ります。

| 情報 | 目的 | 保持・削除 |
| --- | --- | --- |
| YouTube／Jev APIキー（`apiKey.youtube`、`apiKey.jev`） | それぞれのAPIへの認証 | 提供元ごとに設定画面で削除するか、拡張をアンインストールするまで保持します |
| 判定の基準値（`moderation.threshold`） | 次の判定に使う利用者の設定を維持 | 保存した値は再設定・上書きまたは拡張のアンインストールまで保持します |
| 利用条件の確認（`usage.confirmation`） | 利用者が確認した説明の版を識別し、未確認での通信を防ぐ | 版番号のみを端末内に保存します。再起動後も保持し、説明の版変更時は再確認して上書きします。キー削除・取得停止では消しません。アンインストールで削除されます |
| 配信別の非表示情報（`hiddenAuthors.<video ID>`） | 同じ配信で登録済み投稿者の非表示を維持し、個別に解除する | 動画IDに紐づく投稿者ID（`ids`）と取得済み投稿者名（`displayNames`）を明示解除まで保持します。自動期限はありません |
| 解除の世代情報（同じ保存項目内の `revisions`） | 解除前の遅い判定結果による即時再登録を防ぐ | 個別解除後も投稿者IDをキーとする世代情報と空の保存項目が残り、自動期限はありません。設定の全配信削除で保存項目ごと削除できます |

非表示の識別には投稿者IDを使い、名前が同じ投稿者を同一人物とは扱いません。名前は取得済みのものだけを保存・更新し、取得できない名前は「名前不明」と表示します。解除するとその対象の非表示IDと名前は取り除きますが、上記の `revisions` は消えません。取得停止やAPIキー削除でも非表示リストは消えません。非表示ID・名前・世代情報を30日で自動削除したり、定期API取得で更新したりする機能はありません。
設定の「全配信の非表示データを削除」では、非表示ID・名前・`revisions`・空の保存項目を全配信分削除できます。APIキー、判定の基準値、その他の設定とAPIの待機期限は削除しません。

本拡張はChrome同期（`chrome.storage.sync`）を使用しません。WebサイトのlocalStorageや独自サーバーにもこれらの情報を保存しません。端末・OSのバックアップや、通信先の保存まで行われないことを保証するものではありません。

確認の保存エラーが表示された場合は、取得・判定を再開せず、もう一度確認してください。保存領域の故障で、書込が反映されたのに失敗と通知され、未確認状態への書き戻しもできない場合は、再起動後（バックグラウンド再作成・ブラウザ再起動を含む）に成功保存と区別できません。保存領域の完全故障に対する永続的な未確認状態は保証しません。

### ブラウザの利用中だけ扱う情報

| 情報 | 場所・目的 | 保持の範囲 |
| --- | --- | --- |
| 判定に使う本文・投稿時刻と連投の根拠 | バックグラウンドのメモリ。文脈を補足し、連投を判定 | 文脈は投稿時刻で60秒以内・同じ投稿者につき対象込み最大20件。取得停止・対象変更などで本文を解放し、永続保存しません |
| 取得重複ID、投稿者との対応、評価結果などの一時データ | 監視画面／バックグラウンドのメモリ | 追加から60秒の保持期限と件数上限を設けています。判定・保存操作の待機キューにも200件等の上限と60秒の待機期限があります。実行中の通信とは別の制限です |
| 監視画面に表示する本文・投稿者情報・判定 | 開いている監視画面 | 直近最大200件を画面表示します。上限を超えた古い行は取り除きます。表示は判定用60秒窓とは別で、60秒を超えて残ることがあります |
| 対象タブ・動画／ライブチャットID、取得と再試行の待機期限、全配信削除後の取得停止状態 | `chrome.storage.session`。対象の取り違えと早すぎる再取得、削除後の旧取得の自動再開を防ぐ | 拡張のバックグラウンド処理が再作成されても引き継ぎます。全配信削除後は新しい明示取得開始でのみ再開できます。APIキーや本文は保存しません |

本文・判定結果をアーカイブする機能はありません。取得停止だけで表示済みの行を全部消すわけではありません。画面内の表示を消すには監視画面を閉じるか再読み込みしてください。期限処理は拡張が動作している間に行われ、進行中の処理や画面表示まで一律に60秒で消去されるという保証ではありません。

`chrome.storage.session` はブラウザの再起動、拡張の無効化・再読み込み・更新で消去される領域です。長期保存する上記の `chrome.storage.local` とは異なります。[6]

Googleへ送った情報にはGoogleの規約・プライバシーポリシーが適用されます。本拡張の保持期限は、Google側の保存期間を制御するものではありません。[1][2]

TypeSafeによる取り扱いは、[TypeSafeのプライバシーポリシー](https://typesafe.ai/legal/privacy-policy)、[APIサービスの契約（MCA）](https://typesafe.ai/legal/mca)、[データ処理契約（DPA）](https://typesafe.ai/data-processing)、利用者の個別契約・設定を確認してください。[3][4][5]

- TypeSafeの公開プライバシーポリシーには、入力をモデル学習・微調整に使用しない旨の記載があります。一方、MCAの学習に関する条項は顧客の事前同意という条件を含みます。個別契約での条件を含め、すべての利用で例外なく学習されないとは保証しません。[3][4]
- 推論処理、学習への利用、ログやバックアップの保存は別です。学習しない旨の記載だけで、入力が即時に削除されるとは言えません。公開資料は必要な期間の保持、運用記録等の処理やバックアップの残存を説明しています。[3][4][5]
- API入力・出力やログの具体的な保持期間、バックアップの削除日、ゼロ保持の利用可否、各利用者の契約条件は未確認です。本拡張は提供元の保存・学習・人による閲覧の条件を設定・保証しません。
- TypeSafeの公開プライバシーポリシーは、サービスが米国でホストされ、米国へ保存・処理のために情報が移転することを説明しています。日本国内だけに情報がとどまるとは限りません。[3]

## 5. 停止・解除・削除の方法

それぞれ対象が異なります。停止・解除・キー削除だけでは、すべてのデータが消えるわけではありません。

1. **Jevへの送信だけを止める**：監視画面の「Jev判定を停止」を押します。YouTubeからの取得は別に継続し得ます。すでに送信した内容は取り消せません。
2. **取得と判定を止める**：「取得を停止」を押すか、監視画面を閉じます。非表示登録済み投稿者の既存・新着コメントの非表示と、保存済みリストは維持されます。表示済みの行を消す場合は監視画面を閉じるか再読み込みしてください。
3. **投稿者の非表示を解除する**：対象配信の視聴タブで拡張アイコンを押し、監視画面の「この配信の非表示投稿者」から、該当投稿者の「非表示を解除」を押します。同名の場合は補足の投稿者IDも確認してください。非表示IDと名前は削除されますが、解除の世代情報は残ります。別配信は、その配信を選び直します。表示の復元には遅延があり、ページから消えた投稿を再生成しません。解除後の新しい悪質投稿は再登録され得ます。
4. **拡張に保存したAPIキーを削除する**：設定画面の「YouTubeキーを削除」または「Jevキーを削除」を押します。他方のキー、判定の基準値、非表示情報は削除しません。保存欄を空にして保存するだけでは既存キーを削除しません。
5. **提供元でAPIキーを失効させる**：Google CloudまたはTypeSafeの管理画面で別途、削除・取消・ローテーションを行ってください。拡張内の削除は提供元での失効ではありません。
6. **全配信の非表示データだけを削除する**：拡張アイコンの「設定を開く」から、独立したカードの「全配信の非表示データを削除」を押します。確認画面で全配信の解除と設定保持の説明を確認し「削除する」を押してください。「キャンセル」で取り消せます。取得・判定を停止し、全ての `hiddenAuthors.<video ID>` 保存項目（非表示ID・名前・解除の世代情報・空の保存項目）を削除します。APIキー、`moderation.threshold`、その他の設定とAPIの待機期限は保持します。開いている監視画面へ停止・一覧更新を通知し、YouTubeチャットのiframe／popoutへ既存の定期更新で解除を反映します。反映は遅れる場合があり、ページから消えた投稿は再生成しません。削除前の遅い取得・判定・保存結果では復活しませんが、後で明示再開して取得する投稿が悪質なら再び登録され得ます。削除を確認できない場合は成功表示せず、停止状態のまま再試行を案内します。この操作で表示済みのコメント本文を一括消去するわけではありません。
7. **この拡張のブラウザ内データをすべて消す**：取得を停止し、監視画面を閉じた上で、Chromeの `chrome://extensions` を開き「Agent Moderator」を削除（アンインストール）します。拡張のlocal保存は拡張の削除で消去されます。無効化や閲覧履歴・キャッシュの消去だけではlocal保存の全削除になりません。全配信の非表示データ削除は設定・APIキーの一括消去ではありません。端末のバックアップのコピーは別途扱う必要があります。[6]
8. **提供元へ送信済みの情報について削除を求める**：Google／TypeSafeの案内・契約に従い、提供元へ別途依頼してください。TypeSafeのプライバシー窓口は [privacy@typesafe.ai](mailto:privacy@typesafe.ai) です。ログ・バックアップ・法令上の保持などの条件も提供元に確認してください。[2][3]

本拡張の停止・解除・アンインストールは、YouTube上の投稿削除、Googleアカウントの削除、提供元での解約ではありません。送信済み情報や課金履歴の削除を保証するものでもありません。

## 6. 安全性と必要な権限

保存領域を拡張の信頼された画面・バックグラウンド処理に制限し、YouTubeページ側のスクリプトからAPIキーを直接読めないようにしています。ただし、`chrome.storage.local` は暗号化された秘密保管庫ではなく、**APIキーの独自暗号化は実装していません**。パスワード形式の入力欄も表示を隠すためのものです。端末やChromeプロファイルにアクセスできる人からの保護、すべての通信・保存の完全な安全性は保証しません。

現在は `storage`（設定・制御情報の保存）、`activeTab`（利用者が選ぶ視聴タブ）、Google／TypeSafe APIとYouTubeへのアクセス権限を使います。YouTubeの権限は `https://www.youtube.com/*` に及びますが、ページへのスクリプト注入はチャットURLに限定し、対象タブの確認、投稿者ID照合と画面内の非表示・復元に使います。
